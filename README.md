# Вторая практическая работа: EDA датасета Titanic

## О работе

Это вторая практическая работа по машинному обучению. Цель работы — провести первичный разведочный анализ данных (Exploratory Data Analysis, EDA) перед подготовкой модели машинного обучения.

В работе используется датасет пассажиров корабля Titanic. Целевая переменная — `Survived`:

- `0` — пассажир не выжил;
- `1` — пассажир выжил.

## Что требовалось сделать

В рамках практической работы необходимо было:

1. Выполнить общий осмотр датасета: определить размер, типы столбцов, пропуски, дубликаты и количество уникальных значений.
2. Классифицировать признаки на числовые, категориальные, текстовые и идентификаторы.
3. Исследовать распределения числовых признаков и найти выбросы.
4. Исследовать частоты категориальных признаков и редкие категории.
5. Построить не менее трёх типов визуализаций: гистограммы, boxplot, диаграммы частот и диаграммы рассеяния.
6. Построить корреляционную матрицу числовых признаков и pairplot наиболее коррелирующих пар.
7. Проверить баланс целевой переменной, если задача является классификационной.
8. Сформировать письменный список обнаруженных проблем и способов их устранения.

## Что реализовано

Файл `Class/main.py` автоматически:

- загружает `Class/data/titanic.csv`;
- классифицирует признаки;
- выводит информацию о размере, типах, пропусках, уникальных значениях и дубликатах;
- рассчитывает описательные статистики числовых признаков;
- строит гистограммы для `Age` и `Fare`;
- строит boxplot и ищет выбросы по правилу `1.5 * IQR`;
- строит графики частот категориальных признаков;
- анализирует редкие категории;
- строит корреляционную матрицу;
- строит pairplot для наиболее коррелирующих числовых признаков;
- анализирует дисбаланс `Survived`;
- сохраняет итоговый отчёт и графики в `Class/eda_outputs`.

Корреляция в работе интерпретируется как статистическая связь, а не как доказательство причинно-следственной зависимости. Выбросы не удаляются автоматически: сначала необходимо проверить, являются ли они ошибками или реальными наблюдениями.

## Установка и запуск

Откройте PowerShell в корневой папке проекта и выполните:

```powershell
python -m pip install pandas numpy matplotlib seaborn
python Class\main.py
```

После запуска результаты появятся в папке `Class/eda_outputs`.

Если команда `python` не работает, попробуйте вариант с launcher Python:

```powershell
py -m pip install pandas numpy matplotlib seaborn
py Class\main.py
```

## Основные результаты EDA

В датасете 891 строка и 12 столбцов. Обнаружены следующие проблемы:

- 177 пропусков в `Age`;
- 687 пропусков в `Cabin`;
- 2 пропуска в `Embarked`;
- длинный правый хвост и выбросы в `Fare`;
- редкие значения в `SibSp` и `Parch`;
- текстовые признаки `Name`, `Ticket` и `Cabin` требуют отдельного преобразования;
- целевая переменная `Survived` немного несбалансирована: 61.6% против 38.4%.

Подробные выводы и предложения по обработке данных находятся в `Class/eda_outputs/eda_report.txt`.
